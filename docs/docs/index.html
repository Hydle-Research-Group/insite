Welcome

This is the official documentation for Insite, a static website programming language.

The documentation is actively maintained by Hydle Research Group (HRG), and is updated according to changes or additions on Insite.

Installing Insite

Information on installing Insite is available here.

Note that Insite is not available as a distributed binary (yet). You will have to compile it yourself via the Rust compiler.
