Installing Insite

Create a clone of the GitHub repository:

git clone https://Hydle-Research-Group/insite.git

And cd into it.

Running

Make sure you have the Rust compiler and Cargo package manager installed.

To build a site, use:

cargo run -- build

To develop a site and start a webserver, use:

cargo run -- dev
