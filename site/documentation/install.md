## Installing Insite

Create a clone of the GitHub repository:

```sh
git clone https://Hydle-Research-Group/insite.git
```

And `cd` into it.

### Running

Make sure you have the [Rust compiler](https://rust-lang.org/tools/install/) and Cargo package manager installed.

To build a site, use:

```sh
cargo run -- build
```

To develop a site and start a webserver, use:

```sh
cargo run -- dev
```
