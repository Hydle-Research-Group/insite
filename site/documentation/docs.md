## Welcome

This is the official documentation for [Insite](https://github.com/Hydle-Research-Group/insite), a static website programming language. 

The documentation is actively maintained by Hydle Research Group (HRG), and is updated according to changes or additions on Insite.

### Installing Insite

Information on installing Insite is available [here](/insite/docs/install).

Note that Insite is not available as a distributed binary (yet). You will have to compile it yourself via the [Rust compiler](https://rust-lang.org/tools/install/).

### Creating Sites

Information on creating websites with Insite is available [here](/insite/docs/install).
